# Hello World Python Project

This project provides a minimal Python application that returns the classic greeting message `Hello, World!`.

## Requirements

- Python 3
- pytest

## Run locally

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
python -m pip install pytest
python -m pytest -q
```

## Run the app

```bash
python src/hello.py
```
